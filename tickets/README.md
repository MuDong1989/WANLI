# tickets/ —— 多窗口派工协议（2026-08-13 建立）

## 新窗口开机咒语（整段粘贴给新 Claude Code 窗口）

> 读 CLAUDE.md 建立语境 → 读 tickets/README.md（本文件）→ 挑一张状态为"待认领"的工单，
> 把工单头部状态改为"进行中·<你的窗口代号>"并单独 commit 该工单文件 → 按工单施工，
> 只动"可动文件白名单"内的路径。完工后：状态改"完成"、验收栏贴实测输出、commit。

## 五条铁律

1. **引擎冻结**：`engine/` 只读。任何例外先核对 grill-report.md 附录 B 冻结令，且必过 `node engine/test2.js` 全绿（GR9 项+GR-C）。
2. **commit 只 add 白名单路径**，禁 `git add -A`（实录教训：T0 两次 commit 误收 A 线进行时文件）。
3. **每完成一个盒即 commit**，出事按 commit 回滚。
4. **占位数字必须入册** `specs/assumption-registry.md`（CLAUDE.md 硬约束 5）；查不到出处的格子写"未核"，**禁编造**。
5. 工单状态三态：`待认领 / 进行中·窗口代号 / 完成`。认领与完工都要改状态并 commit——状态栏就是锁。
