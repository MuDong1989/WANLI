> 工单 P0-8 交付物（2026-08-13，窗口 build CC）。四名角省 ×（城投债信用利差 / 骗补通报省域密度 / 财政自给率）对照表，
> 每格附来源与映射公式——把 A1/A5/A7 的标定路径从"承诺"变成"可点开"。
>
> **一句话结论**：**A7（财政自给率）方向成立，且排序在挤掉辽宁水分后与引擎逐位同序**——
> 引擎 `JS .90 > HB .50 > JX .45 > LN .40`，实测 `JS .829 > HB .5275 > JX .490 > LN .460`，四省偏差 +5.3%～−13.1%。
> 但这条结论**依赖一个前提**：辽宁 2014 年的报表自给率是 **0.628**，按报表数排辽宁会跳到第二位、引擎排序当场垮掉；
> 只有采用辽宁 2015 年"挤水分"后的 0.460（省长 2017 年公开确认 2011–2014 财政数据造假、2014 年虚增比例最高达 23%），

>
> 另两指数：**城投利差**的量值（bp）在 2012–2015 窗口**未核**（公开可得的分省利差数据集中在 2021 年之后），
> 但**序数已核**且与 A1 的兑现信誉排序完全一致（广发固收四梯队：江苏一 / 江西二 / 河北三 / 辽宁四）。
> **骗补通报省域密度**：分子有（财政部 2016 通报五家典型，命中江苏 2 家）、**分母（各省客车/光伏产业基数）无**，
> 密度口径**算不出来**，整列标未核——不是没查，是这个指标在公开数据下不成立，详见 §3。

### 1.3 辽宁 2014 的水分（本页最关键的一格）

辽宁省长 2017-01-17 在省人代会政府工作报告中**首次公开确认**：2011–2014 年全省所辖市县存在财政数据造假，
"官出数字、数字出官"，虚增数额与比例逐年上升，**2014 年最为严重、虚增比例约 23%**。

- 出处：[新华网《辽宁首次对外确认2011年至2014年存在经济数据造假问题》](http://www.xinhuanet.com/politics/2017-01/17/c_129450972.htm)、[财新《辽宁确认2011至2014年经济数据造假》](https://china.caixin.com/m/2017-01-17/101044940.html)｜**已核**
- 2015 年收入断崖式下降 33.4% 的官方解释即"按'三严三实'依法依规组织财政收入，**做实了财政收入**"（见 1.2 出处原文），
  与造假确认互为印证。
- 按虚增 23% 反推 2014 真实收入 ≈ 3192.8 × 0.77 = **2458.5 亿元**，对应自给率 ≈ **0.484**——
  该反推**未核**（"虚增比例 23%"的分母口径原文未明示，是占报表收入还是占真实收入不确定），仅作量级参考，不进对表。

### 1.4 排序检验（A7 的核心结论）

| 口径 | 排序 | 与引擎是否同序 |
|---|---|---|
| **引擎现值** | JS .90 > HB .50 > JX .45 > LN .40 | — |
| 实测·2014 报表数 | JS .854 > **LN .628** > HB .5275 > JX .485 | ✗ 辽宁错位至第二 |
| 实测·辽宁取挤水分后（JS/JX 取 2015、HB 取 2014、LN 取 2015） | JS .829 > HB .5275 > JX .490 > LN .460 | ✓ **逐位同序** |

**结论**：A7 四个占位值**方向全部成立**，最大偏差 −13.1%（辽宁），其余三省在 ±8% 内；
排序成立的前提是采用辽宁挤水分后的口径。引擎把辽宁设成四省最低，**押对了真实值、押错了当年的官方报表值**——
这一点必须在路演与文档里主动交代，否则被人用 2014 报表数一查就是"排序错了"。

### 1.5 顺带得到的 A1 方向证据（名义优惠 incentive）

引擎 `incentive` 是 A .12 < B .20 < C .30，即**财力越弱的带、名义优惠给得越高**。
实测自给率 JS 0.829 ≫ HB 0.528 ≈ JX 0.490 > LN 0.460 恰好是反序——
"财力弱省用更高名义优惠竞争招商"这一**方向**与数据一致。
但这只是**符号方向**：.12/.20/.30 三个具体数值仍**未核**（需各省招商引资奖补文件的实际补贴率），A1 不因此升档。

**为什么量值整列未核**：本轮检索到的分省城投利差数据集中在 **2021 年之后**（广发 2022、标普信评 2026 等），

属于典型的时间错配，**宁可标未核也不填**。

**补核路径**（赛后）：① Wind「城投债分省信用利差」历史序列（需终端）；② 中债估值分省曲线；
③ 学术论文里的分省利差面板表——检索式建议 `城投债 信用利差 省级面板 2010-2016 财政透明度` 之类，
优先找带完整年份列的表格附录；④ 辽宁换届（A4，t5 起 cred→0.22）需要的是**换届窗口前后的利差跳变**，
比水平值更关键，检索时应直接锁定"省级党政主官更替 事件研究 城投利差"。

**已核的单点参考（不进对表，仅记录）**：2021 年前三季度江苏省城投债发行利差加权均值 160.48bp，
省内苏南（苏州/南通/无锡/南京）均 <150bp、苏北（宿迁/镇江/盐城）均 >300bp——
省内分化大于部分省际分化。此数为二手转述（[资产界转载报告](http://m.zichanjie.com/article/176517.html)），
原报告表格**未直读**，且年份不匹配，故标**未核**。它的价值在于提醒：真做省级标定时，
**省内分化可能压过省际分化**，届时 A1 的"一省一个 cred"本身要被质疑。

### 3.2 为什么整列标未核（这是结论，不是偷懒）

1. **分母缺失，密度算不出来**。江苏在五家典型里占 2 家，但江苏同时是全国客车与新能源车产业基数最大的省之一；
   不除以产业基数，2 家既可能意味着"查得严"，也可能意味着"厂子多"，**方向都读不出来**。
2. **分子样本量 n=5，统计上无意义**。四省里三省为 0，任何"密度排序"都是噪声。
3. **金太阳侧完全无省域数据**，而金太阳恰恰是本场景 t<8 装机补贴期的对应物——
   最该有数据的那一段，公开信息里是空的。
4. **因果方向本身可疑**：中央通报数同时受"地方执行松紧"与"中央是否盯上这个省"影响，
   后者在 2016 年那轮检查里明显与产业规模相关。即便凑齐分母，这个指标离"执行折扣"也隔着一层。

**因此本列按工单规定的兜底口径处理：标「数据不可得（赛后）」**，并给出补核路径：
① 审计署历年《审计工作报告》中新能源补贴专项的分地区问题金额（需逐年翻正文，非结构化）；
② 各省财政厅/审计厅的补助资金专项检查通报（分散、公开程度不一）；
③ 替代指标建议——**改用"省级财政专项资金违规问题金额 / 该省一般公共预算支出"**，
   分子分母都在审计报告与决算里可得，比骗补计数更可算，代价是离"光伏骗补"更远。
