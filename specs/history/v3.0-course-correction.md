# 万历 v3.0 方向修正案 —— 从"光伏模拟器"到"政企推演场"

> 本文档记录三项用户裁决及其全部连锁后果，**取代 v2.1 §0/§2/§3.4 的对应表述**，其余章节继续有效。
> 裁决一：光伏只是因子提取案例与演示件，产品是通用政企推演场。
> 裁决二：技术栈定稿（见 §3）。
> 裁决三：地域用真实中国地图，弃三风格化区域。
> 修正案生效后**重新设计冻结**。

---

## 1. 定位翻转：什么翻、什么不翻

**翻的是叙事与抽象层，不翻架构。** v2.1 的引擎本就是场景解耦的（ScenarioPack），但产品身份、demo 开场、文档结构都以光伏为主语——这是要纠正的。翻转后：

| 层 | v2.1（光伏主语） | v3.0（推演场主语） |
|---|---|---|
| 产品定位语 | 光伏产业政企博弈推演 | **政企互动推演场引擎**；光伏 2009–2018 是第一个校验完成的场景包 |
| Demo 开场 | 直接进光伏史实回放 | 先亮**场景选择页**（光伏包 / 客车包 / 自定义），再加载光伏包 |
| 第二场景包 | P0-6 半成品、可选 | **升级为必做演示桥段**：现场 30 秒加载新能源客车骗补包（2013–2016），跑三回合，"换产业不改一行引擎代码" |
| 因子体系 | 隐含在 CFG 参数里 | **一等公民交付物**：因子注册表（§2） |
| 校验主张 | 光伏史实复现 | 引擎级主张：**给定因子表即可推演任意政企场景**；光伏是"已吹过风洞的第一架飞机" |

**不翻的**（原理由依然成立）：深案例策略——通用性必须靠一个打穿的案例证明，评审是经济学家，会往深处扎；光伏仍是 Exhibit A，客车是可移植性的最小证明，48h 内不做第二个完整产业。

## 2. 因子体系 v1（推演场的"元语言"）

推演场 = 五张因子表 + 一个市场出清核。任何场景包都是对五张表的一次实例化：

**① 政策因子库**（按作用通道分类，每条带 theory_ref 与参数域）
- 供给成本端：投入型补贴（装机/购置/产能返现）、税收减免、信贷贴息、土地要素
- 产出激励端：产出型补贴（度电/里程/销量）、政府采购、价格支持
- 准入与秩序端：牌照/规范条件（工信部式白名单）、产能审批、强制退出
- 监督端：核查力度、处罚倍率、媒体环境开放度
- 贸易端：关税、出口退税、（外生）他国贸易救济
光伏包激活：{投入型, 产出型, 核查}；客车包激活：{购置补贴, 里程门槛(准入), 核查}——同一张表，不同掩码。

**② 企业行动契约**（通用动作空间 + 场景掩码）
`{进入/退出, 扩产 dK, 研发 rd, 合规姿态 fake, 定价偏移, 区域选址, 游说(完整版)}`——光伏包掩码开 {dK, rd, fake, 选址}；行动契约就是 LLM/规则/群演三档共用的那份 JSON schema，不变。

**③ 主体因子**：trait 六维（rnd/expand/risk/integrity/herd/patience）**天然产业无关**——v2.1 最经得起翻转的设计决策；A 股六指标→六 trait 的校准管线对任何 A 股行业成立。

**④ 制度因子（区域）**：`{优惠能力, 兑现信誉, 执行折扣, 要素成本, 集聚}`——从"三带各一组"扩展为"**省级各一组**"（§4）。

**⑤ 结果因子**：财政/流失/成本前沿/集中度/存活谱(名角+长尾)/舆情/区域份额——已通用。

ScenarioPack 相应升级为 **v2.2**：`policy.tools` 改为引用政策因子库条目；`population.archetypes` 引用原型库；`regions` 改为省级制度表引用 + 事件列表。

## 3. 技术栈定稿

**现状（已交付的两个演示件）**：零构建单文件——原生 JS + three.js r128（cdnjs）/ ECharts 5.5（cdnjs）+ Canvas 2D 手绘图表 + 纯 CSS HUD；引擎为纯 JS 同构模块（node 跑 GR 回归 / 浏览器跑演示），无框架无打包。这是"演示件栈"，其价值是零依赖、断网可救、AI 编码代理迭代最快。

**产品栈（48h 与之后的正式方案）**：

| 层 | 选型 | 理由 | 离线策略 |
|---|---|---|---|
| 工程壳 | **Vite + Vue 3 + TypeScript** | 中文大屏生态最顺手；场景选择页/双仪表盘/扫掠页需要组件化 | `vite-plugin-singlefile` 出单文件保底 |
| 引擎 | **纯 TS 模块，零依赖** | 同构三跑：浏览器主线程(演示)/Web Worker(扫掠不卡 UI)/node CLI(GR 回归+夜跑) | 天然离线 |
| 地图 | **ECharts 5 geo + 本地 GeoJSON**；`echarts-gl` 为楼海 3D 升级路径（bar3D on map） | 一库同吃地图+图表，团队熟悉，cdnjs 已验证；deck.gl 视觉更强但 CDN 与学习成本不确定，列为备选不列为基线 | GeoJSON 内嵌；echarts.min.js 本地化一行改 src |
| 仪表图表 | ECharts（同上） | 替换手绘 sparkline | 同上 |
| 3D 沙盘 | three.js **保留为可选"抽象沙盘视图"** | 已交付、有辨识度；地图视图为主视图后它降级为切换项 | 已单文件 |
| LLM 层 | **node 薄代理（~40 行 express）+ JSON 缓存落盘** | 浏览器直连各家 API 有 CORS 与密钥暴露问题；缓存回放是演示主线 | 缓存即离线 |
| 数据 | 静态 JSON/GeoJSON/CSV，无数据库 | 48h 不碰持久化 | 天然离线 |

**迁移代价声明**：两个已交付单文件不作废——三维沙盘转"抽象视图"，地图壳层就是新主视图的骨架；引擎一行不迁移（它从第一天就是独立模块，这次转向零成本正是这个决策的回报）。

## 4. 真实中国地图方案（弃三风格化区域）

**已交付证明件**：`wanli-map-shell.html`——同一个引擎（GR1–9 通过版原封不动）+ 一层"制度带→省份"适配器 + ECharts 真实地图。名角落位原型公司真实城市（天阳@无锡、隆盛@西安、汉光@上海、稳达@东莞、跨界@深圳、小盛@沈阳），226 家长尾按产业集聚权重散布真实省份，中央★北京，补贴飞线、骗补涟漪、省域按有效核查着色。**交互契约与三维版完全一致**（接管/双宇宙/五段卡/日志）——渲染层可插拔得证。

**从"三带"到"省级"的升级路径**（真正的工作量在数据不在代码）：
- 选址函数不变，只把 j 的取值域从 3 扩到 31：`U_j = α·优惠_j·信誉_j + β·集聚_j − 成本_j + 洼地虹吸项 + ε`；
- 有效核查公式不变：`effA_j = 中央核查 × (1 − 执行折扣_j)`；
- 群演/进入/退出逻辑不变。

**三道护栏（真实地图的风险管理，缺一不可）**：

1. **公开指数映射，不做自家评价**。省级制度向量必须从公开数据映射，校验页公开映射公式，把"敏感评价"转化为"公开数据转述"：
   - 兑现信誉 ← **城投债信用利差**（市场给地方政府信用定的价——量化血统的校准源，评委席上的经济学家会认）；
   - 执行折扣 ← 审计署/财政部历年骗补通报的省域密度（金太阳、新能源车骗补处罚名单均公开且带地理分布）；
   - 优惠能力 ← 财政自给率 + 产业引导基金规模；
   - 要素成本 ← 工业地价/电价/劳动力成本公开统计；
   - 营商环境类指数作交叉验证。
   任何映射不到的省份参数 = 全国均值，页面明示。
2. **政府 agent 分层（名角省 + 群演省）**，与企业侧同构：3–5 个剧情相关省份做深度地方 agent（有锦标赛动机、有换届事件钩子），其余省份规则驱动（制度向量静态或缓变）。避免 31 套异质深度 agent 的参数灾难。
3. **地图合规与叙事纪律**：公开演示必须替换为自然资源部标准地图（带审图号，含南海诸岛插图与完整国界）——已列 P0；换届类叙事事件默认绑定"演示事件"标注或有公开报道支撑的案例措辞，不对真实省份作无出处的负面断言。

**风格化三区域的遗产**：不删除。它降级为"制度带"概念（沿海/中西部/东北是制度聚类的三个簇心），省级参数缺失时的回退层，也是教学模式的简化视图。
