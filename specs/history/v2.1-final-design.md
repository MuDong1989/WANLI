## 0. 定位与评审映射

光伏产业 2009–2018 政企博弈推演场。自动驾驶复现史实 → 任意时点接管 → 同种子双宇宙锁步对照。回应赛题三大参考场景：场景③补贴-进入-产能（主线）、场景②政策兑现与承诺可信度（区域层）、场景①招商地区竞争（选址函数）。

| 评审维度 | 我们的答案 |
|---|---|
| 实时可见变化 | 楼海生长/熄灯、金流粒子、双宇宙分叉曲线 |
| 决策链可追溯 | 五段决策卡：观测→记忆→依据→行动→独白 |
| 多分支对比 | 同种子锁步双宇宙 + 扫掠 Pareto 前沿页 |
| 有人想用 | 三出口：政研沙盘 / 企业战略压力测试 / 政经教学 |

**路演挡箭牌**（对量化质疑）："风洞里的飞机不是真飞机，但没人敢不吹风洞就上天。我们校验的是风格化事实的复现，不是点位预测。"

## 1. 模式系统（同一引擎，三个变量）

双身份 × 双模式 × 批量扫掠，全部由三个变量组合而成：**接管对象**（中央 / 某企业 / 无）、**仪表盘**（政府视角 / 企业视角）、**批量**（单次交互 / 无头扫掠）。

- **A 政府视角**：接管政策三元组 `{工具, 强度, 核查}`，看产业总量、财政、流失、舆情、区域份额。**demo 主线。**
- **B 企业视角**：接管一家名角的 `{扩产, 研发, 造假}`，其余照旧，看自身生存与排名。中环，限时盒 4h，超时降级为 PPT 截图。
- **C 扫掠**：政策空间网格/LHS 采样 × 多种子，无头夜跑数千次 → 规则档全量 + LLM 复跑 top-k（双保真）→ 预渲染 ECharts 结果页，产出（财政投入, 成本下降, 流失, 出清烈度）的 Pareto 有效前沿。不做交互式扫掠 UI。

## 2. ScenarioPack v2.1（场景即数据包）

引擎与场景解耦；换产业=换 JSON。五块结构：

```
meta:       {id, name, period:[2009,2018], dt:0.5(年), rounds, seed}
factors:    {D0, demandGrowth, growthDecay, shock:{round,factor}, C0,
             frontierDrift, frontierRnD, priceCurve:{A,B,exp,rMax}, capexK,
             financing_cost:0 /*占位:利率通道,本场景不启用*/}
policy:     {tools:[capacity,generation,none], intensity:[0,100], audit:[0,100],
             script:[{until:8,mode:capacity,i:60,a:20}, {until:18,mode:generation,i:55,a:55},
                     {until:20,mode:generation,i:15,a:55}]}   // 金太阳→度电→531
regions:    [{id,name, incentive, cred, disc, cost}×3, turnover:{round:5,region:C,cred:0.22}]
population: {cast:[6-12家 名角], extras:{N0:200, K~Pareto(kmin,α,cap), traitMix, entry, exit}}
validation: {targets:[fit/blind/holdout 三类风格化事实], series_real:[真实价格/装机序列,赛前填]}
```

**dt 折算规则**（所有率参数按年标注，载入时折算）：增长率 `(1+g)^dt-1`；漂移 `η·dt`；概率 `1-(1-p)^dt`。写进加载器单测。

**theory_ref 字段**：每个机制参数附注册表编号（如 `frontierRnD → #3 Wright学习曲线`），校验页可点开溯源。

## 3. 主体系统

### 3.1 名角（6–12 家，深度 agent）

四件套：**状态**（K, cash, f, 虚报存量, 区域, 在建, 既定计划）+ **trait 向量** + **记忆流** + **decide()**。

**trait 向量（六维，[0,1]，非 embedding）**：`[rnd, expand, risk, integrity, herd, patience]`。支持四种运算：距离（最近邻原型选独白模板）、漂移（演化）、聚类（与 A 股同空间→可校准）、抽样（群演生成/消融）。

**目标来源三层**（企业无显式效用函数——行为主义立场，Cyert&March 满意化 / Nelson-Winter 惯例）：
1. 理论定结构：六原型来自演化经济学 + Baumol 才能配置（生产性/寻租性企业家精神）；
2. 数据定数值：A 股六指标→六 trait 的**揭示性偏好**聚类（详见 §7.3）；
3. 财税访谈先验兜底（提纲已交付）。

### 3.2 群演（~200 家长尾，规则驱动）

幂律规模（Axtell 2001）：`K ~ Pareto(kmin=0.0018, α=1.15, cap=0.04)`，trait-lite 三维（integrity/herd/expand）。与名角共用同一供给池与销售分配。
- **进入**：`n = min(6, 1+3·max(0,行业毛利−0.8))`；**政策塑造物种**：装机补贴下低 integrity 进入者占比 +0.15×强度——政策不仅筛选行为，还塑造进入物种；
- **选址函数**（场景①②）：`U_j = 2.2·优惠_j·信誉_j + 1.4·集聚份额_j − 要素成本_j + ε`；低 integrity 者追加**监管洼地虹吸项** `+(45−实核_j)/100×1.2`；
- **退出**：cash<0 即死。已实测：出清潮 2011 起、2013 上半年单回合 52 家倒闭（破产潮镜头）。

### 3.3 政府侧

- **中央（可接管）**：三元组 `{工具, 强度, 核查}`。
- **部委层（外环，PPT+完整版）**：目标**方向与排序有史料**——三定方案 + 文件署名史（金太阳=财建[2009]397号财政部；度电=发改价格[2013]1638号；制造规范=工信部2013；双反应对=商务部；531=三部委会签）。形式=同一状态表上的权重向量（发改/能源重装机降本；财政重支出缺口；工信重升级集中度）。**权重校准法**：调权重使部委讨价还价内生复现 2013/2018 政策时点（用历史时点反推权重，类比期权价反推隐含波动率）。部委分歧→拖延→**政策时滞内生化**（Friedman lag 涌现）。
- **地方（三区域，内环已实现）**：周黎安锦标赛。核心不等式：**有效核查 = 中央核查 × (1 − 地方执行折扣)**——委托代理的一行代码表达。实测：装机60+核查70 时骗补 A/B/C = 0/0/61，全部集中 C 省（实核 63/53/39）。
- **媒体**：观测骗补事件流→曝光；中央核查≥45 时曝光触发**中央直查追缴**（绕过地方），否则不了了之+舆情恶化。舆情<40 触发全国性问责事件。

### 3.4 区域层参数（风格化，非真实省份）

| 区域 | 名义优惠 | 兑现信誉 | 执行折扣 | 要素成本 | 事件 |
|---|---|---|---|---|---|
| A 沿海 | 0.12 | 0.85 | 0.10 | 0.15 | — |
| B 中部 | 0.20 | 0.70 | 0.25 | 0.08 | — |
| C 东北 | 0.30 | 0.45→**0.22** | 0.45 | 0.05 | t=5 换届："新官不理旧账" |

涌现叙事：合肥模式=优惠×高兑现；宁德=集聚项；"投资不过山海关"=信誉陷阱（换届后 C 份额萎缩至 1–2%，实测复现）。

## 4. 演化与决策时滞

**原型演化三通道并存**（=复制者动态的离散实现）：
1. 存量漂移：`Δtrait = η·dt·(标杆−自身)`，**不对称成本**（学坏快、回头慢，η=0.15/年，回头×0.5）；
2. 进入选择：政策塑形进入者 trait 分布（§3.2）；
3. 差异化死亡：低适应度原型被出清。

**决策时滞三件**：
- 蛛网结构已内生（当期价决策/下期投产），路演明示 Ezekiel 1938；
- **粘性重规划**（组织惯性，Calvo/Hannan-Freeman）：激进者 `plan.left=1`，非紧急不改计划——"小快灵骗补者最先转向、大集团刹不住车"。紧急阈值 cash<0.4×capex 强制重议。已实现并通过回归；
- 付费调研（Sims 理性疏忽）=完整版，MVP 不做。

## 5. 统一决策契约与五段决策卡

三档实现共用一个契约（输入 obs+mems → 输出 JSON）：

```
obs:  {t, P, Cf, margin, r, policy{mode,intensity,audit}, effA(本地实核), capex, avgMargin}
out:  {dK, rd, fake, note(独白), rule(依据)}
```

- 群演：N×6 trait 矩阵 × 信号向量，一次矩阵运算；
- 规则名角：通用函数+性格招式，rule 自动填；
- LLM 名角：trait→人设 prompt 段 + 技能卡 + 检索记忆 top-2 → 同一 JSON。**结构化输出失败三次→自动降级规则档**（demo 永不裸奔）。

**记忆流 lite**（斯坦福小镇三要素的规则版）：事件类型 {policy_change, peer_bankrupt, audit_hit, loss, windfall, media}，检索分 = 显著性 × 0.75^时距 × 情境相关矩阵，top-2 进入决策卡。**记忆必须有行为后果**（每一档实现都要满足）：规则档已内置两个因果钩子——骗补者两期内有被查处记忆→蛰伏（特定威慑），激进者一期内有同行破产记忆→常规扩张×0.65（兔死狐悲，逆势加码分支不受影响以保人设）；LLM 档中记忆经检索进入 prompt 直接参与推理。

**五段决策卡**（评审维度"决策链可追溯"的正面回答）：**壹观测 / 贰调取记忆 / 叁决策依据 / 肆行动 / 伍内心独白**。已实现。

**消融开关**（demo 彩蛋）：关记忆→只剩观测；关人设→trait 置种群均值→行为同质化。"心理结构不是装饰，是行为的原因。"

### 7.2 三类校验目标

- **fit（瞄准复现）**：GR1–6 时序类事实；
- **blind（未瞄准命中）**：路演最高光——校准时没对准、却自己长出来的模式（法拍收购产能易主、监管洼地让骗补者多活三年、C 省份额萎缩）；
- **holdout（留出）**：2018 后半段序列不参与校准，仅作对照展示。

### 7.3 A 股校准管线（赛前，QMT/xtquant）

六指标→六 trait：研发强度→rnd；资本开支增速→expand；杠杆→risk；违规处罚（代理：审计非标+ST）→integrity；蹭热点（代理：商誉/在建激增，锚 Cooper et al. 2001 更名效应）→herd；现金分红→patience。聚类=战略群组（Hunt 1972 / McGee&Thomas 1986）。**分两时代聚类**（2009–12 含美股中概 SEC 数据补样；2013–18 A 股）→"政策塑造物种"的实证页。已知坑：2009–12 主角在美股港股，样本要补。

### 7.4 专家面校验

财税专家 90 分钟访谈（提纲已交付）：原型先验 / playbook 三元组 / 区域实操 / 看盘挑错。访谈金句进路演页（"专家说这个骗补节奏和他见过的案子一致"）。

## 8. 三环开发结构（防 60% 死法）

- **内环 = 五分钟 demo 关键路径**：史实自动驾驶回放 + 群演楼海 + 接管分叉 + 五段决策卡 + 校验页 + 终局复盘。此路不通，一切归零。

- **外环（只活在 PPT）**：部委讨价还价、信誉陷阱动态循环、多基座分布、付费调研。

**设计冻结规则**：新想法→backlog（注册表照登记），不进 sprint；换入必换出；每次合入跑 GR1–9。

## 10. v1→v2.1 重校准记录（诚实披露）

群演 200 家加入供给池后重校准：D0 4.2→5.8（容纳长尾供给），divRate 0.18→0.24（削名角繁荣期战争储备，恢复天阳死期）。副产品叙事升级：小盛在 C 省监管洼地几乎不被查（实核 11），骗补现金撑到 2016 年才饿死——**"监管洼地让骗补者多活了三年"**，比 v1 的 2013 罚死更有讲头。所有改动以 GR1–9 全过为准绳。
