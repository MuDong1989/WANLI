# 万历 · 政策树规格 v1（光伏包 21 节点）

> 政策因子不是三个旋钮，是一棵可组合的树。本文是树的契约：节点、编译器、预算、解锁语义、GR 安全规则。

## 0. 架构

```
政策树（UI 状态机：节点×等级）
   └─ compilePolicy(activeNodes) → { mode, intensity, audit, x{…} }
                                        └─ 引擎 step(policy)
```
- **核心三元组**（mode/intensity/audit）与 v2.1 完全兼容——旧剧本、旧 GR 一个字节都不改。
- **扩展通道 x**：全部字段带默认值，默认=旧行为。字段清单：
  `opexRelief capexMul rdCostMul entryBonus entryGateF entryGateK0 lowIntegCut dKCapMul subEligF forceExit fineMult mediaProb discountMul demandBonus shockMul opinionDrip fiscalDrip`
- 叠加规则：加法类（demandBonus 等）累加；倍率类（capexMul/shockMul/discountMul 等）连乘；门槛类取最后写入。

## 1. 行动点：政策注意力预算

每回合 **3 点行动力**；启用/升级/降级/废止各 1 点（中央巡查组占 2 点）。理论出处：理性疏忽（Sims 2003）的政府侧——注意力是稀缺品，"什么都调"不是一个可行的政策组合。史实剧本恰好用满 t8 的 3 点（废装机+启度电+升核查）。

## 2. 解锁语义（三类）+ 互斥

- **前置 req**：光伏扶贫/全额消纳 需先有度电补贴；领跑者 需 度电+规范条件。
- **状态解锁 unlock(sim)**：平价上网 需 成本前沿 < 4 元/W（政策可行性内生于产业状态——树随世界生长）；海外建厂 需 t≥7（双反之后）。
- **时间窗 window**：双反谈判仅 2011下–2012下 可启用，错过即永久关闭。
- **互斥 mutex**：装机补贴 ⊕ 度电补贴（引擎单主模式；混合补贴进 backlog）。

## 4. GR 安全规则（本规格最重要的一条）

**史实自动驾驶只点亮校准三件套（装机/度电/核查），其余 18 个节点是用户的反事实能力，不进史实剧本。** 已验证：节点化剧本编译结果与旧三元组 20/20 回合逐位相等，模拟历史逐位一致，GR1–9 全绿。带史实标注但未入剧本的节点（规范条件/领跑者等）在 tooltip 中如实标注"史实回放未启用"——把它们纳入史实剧本需要重校准（专项卡，赛中做，做完 GR 重定标）。**新节点效果只做加法，永不修改基线路径的既有行为。**

## 5. 已验证

- 剧本编译等价 20/20；模拟史实逐位一致；GR1–9 全绿（引擎扩展后复跑）。
- 反事实链：核查 Lv3 管不住 C 省（骗补 0/0/61）→ 加巡查组归零（0/0/0）——委托代理问题在树内有政策解。
- 时间线：任意回合同种子重演逐位一致；分叉后组合政策（规范Lv2+重罚+巡查）流失 44→35 亿、长尾存活 108→122。

## 6. 扫掠的组合爆炸对策

3^2×2^5×…≈10^8 组合不可网格化。对策：① 8–10 个**策略原型**（严监管型/放水型/精准滴灌型/秩序优先型…）做预设组合扫掠；② 连续强度上做拉丁超立方；③ backlog：bandit 式组合搜索。帕累托前沿改为"策略原型空间"上呈现。
