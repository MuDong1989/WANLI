# 决策日志 —— 已审裁决册（拷打防重犁）

> 每条 = {决定, 被否的备选, 理由, **推翻条件**}。拷打欲推翻某条，须给出满足推翻条件的新论据，否则视为重犁。[E#]=evidence.md。

**D1 · 一深一薄的案例策略**
决定：深打光伏 + 薄做客车换包。被否：多案例平铺 / 纯通用无案例。理由：通用性必须靠打穿的案例证明，经济学评委会往深处扎；换包 30 秒是可移植性的最小可证伪证明。推翻条件：评审明确表示广度权重高于深度。

**D2 · 产品主语=推演场，光伏=Exhibit A**
决定：定位翻转（v3.0），架构不翻（引擎本就场景解耦）。被否：光伏模拟器定位。理由：赛题是推演场；工具靠已验证的第一架飞机卖。推翻条件：无（用户裁决，方向性）。

**D3 · 技术栈两轨**
决定：演示件=零构建单文件+cdnjs；产品=Vite+Vue3+TS+纯TS引擎三跑+ECharts geo；LLM 走 node 薄代理+缓存。被否：deck.gl 为基线（CDN 与学习成本不确定，降备选）；全框架化演示件（断网风险）。推翻条件：deck.gl 离线打包验证通过且团队有余力。

**D4 · 真实中国地图 + 三护栏**
决定：真实地图渲染，省级参数走公开指数映射，政府 agent 分层，审图号合规。被否：三风格化区域为最终形态（降级为制度带/回退层）。理由：政企语境代入感 + 省级实证传统 + 城投利差等可测锚存在。推翻条件：公开指数管线（P0-8）证实不可行。

**D5 · 中央不内生 = 玩家席**
决定：中央为玩家席+史实自动驾驶；"中央自动修正规则"仅作研究镜头场景选项。被否：GPT 建议的全反馈闭环（中央 agent 化）。理由：中央内生化=风洞退化为观景台，用户从实验者变观众。推翻条件：出现"政策学习基线"的明确评审需求（届时以 ai-economist 模式做场景选项，仍不进主循环）。

**D6 · 部门不做独立 agent → 名角省内阁席位票决**
决定：招商/财政/监管为名角省决策卡内的席位（有立场、可测输入、可校准权重），省行动=票决。被否：GPT 建议的每地三部门独立 agent（提议权/否决权）。理由：部门议价权重无任何可校准数据源；测得的外生变量 > 编造的内生机制——GPT 自己的原则支持我们的做法。推翻条件：找到部门级议价的可测数据源（如分部门预算博弈的公开痕迹）。已落地：[E4]。

**D7 · 群演保留约 230 且升级数据出处**
决定：保留并双源校准（上市公司定类型配比与头部、行业普查定总量与尾形）。被否：GPT 建议砍群演。理由：群演是生态层承重墙——骗补主力、死亡潮（GR8 校验标的）、进入退出流全在此层；向量化后零成本。推翻条件：无（砍它等于拆生态层地基）。

**D8 · 第二场景包升必做**
决定：客车骗补包 30 秒换包为 demo 桥段。被否：GPT 建议砍第二包。理由："换产业不换引擎"是通用性主张的可证伪性所在。推翻条件：时间盒爆炸时降级为录屏。

**D9 · 政策树取代三旋钮 + GR 安全规则**
决定：21 节点/AP=3/解锁三类/互斥；史实自动驾驶只点校准三件套，新节点只加反事实能力。理由：政策因子远不止三个选项（用户裁决）；GR 安全规则保住九项回归逐位不变 [E2]。推翻条件：史实剧本需纳入更多真实节点（规范条件/领跑者）时，走专项重校准卡。

**D10 · 进入选址 + 迁址 v1，多 home v2**
决定：单厂址+迁址动作（费/冷却/减产）先行；K 向量化的多区域摆放为 v2 手术。被否：立即多 home 重构（GPT 再提案）。理由：成本核算——全国单一出清不动，v1 已可回答"资源放哪"的入口题。推翻条件：企业镜头用户测试证明单厂址不可接受。

**D11 · 地方配套通道默认关、场景开**
决定：localMatchK 基线 0（GR 安全），企业镜头场景 1.0。理由：新制度通道动基线，须过重校准闸；台账作为免费副产品先行。推翻条件：正式决定将配套纳入史实基线（届时整体重校准）。

**D12 · 游说=注册表开关默认关（建议中，待用户终裁）**
建议：不做玩家动作，作规范设定开关供研究镜头扫敏感性。理由：开=闭环成双向博弈（题眼）但校准与敏感性难度抬一个量级。状态：**未终裁**——这是日志中唯一一条建议而非裁决。

**D13 · 名角 6→8：政企绑定型 + 国资型**
决定：第七席维赛（赛维原型，软预算约束）、第八席国晶（中环原型，逆周期）。被否：垂直一体化席（需多环节市场，backlog）。理由：名角席=机制席，政企绑定是政企互动的机制之王且必须企业侧+政府侧各一深度 agent 才演得出。已落地并重校准 [E1][E7]。推翻条件：无（用户批准并已过 GR）。

**D14 · 4 名角省内阁化 + 软预算约束 ≤2 次**
决定：江苏/江西/河北/辽宁三席位票决；江西救助限 2 次。已落地 [E4][E7]。理由：见 D6；救助上限防僵尸永生。推翻条件：A8 标定后调整次数。

**D15 · 项目 = 合同层，非状态中心**
决定：引擎（主体+出清）为状态中心；项目为 v2 合同层（谈判单位/里程碑/违约喂台账）+ 免费投影视图 [E10]。被否：项目生命周期驱动模拟的本体（GPT 转述的 ADR 方案）。理由：投影不对称性——引擎→项目免费，项目→引擎不可能；价格形成/记忆/廉价分叉在项目本体中无处安放。状态：用户确认仓库无分叉，本条为定位记录。推翻条件：无。

**D16 · 决策可视化优先级**
决定：剧场四拍 > 记忆连线 > 规则徽章热力图 > 翻转因子 > 胶片；统摄原则=显著度调度（默认安静异常发声）。理由：决策过程从拉取式改推送式，但注意力有预算。推翻条件：demo 排练时的节奏实测。

**D17 · 对斯坦福小镇的定位应答**
决定：不对标全深度 25 人，走"约三百独立决策体的深度金字塔"（深度 12：8 名角+4 省内阁）。理由：全 LLM 化在成本上不可行（扫掠=百万级调用）、在科学上有害（不可复现杀死分叉/Shapley/GR）。推翻条件：无（除非放弃确定性纪律，而那是 CLAUDE.md 硬约束 2）。
