# 万历 v3.1 —— 现行统一设计（拷打版）

> 本文取代 v2.1-final-design 与 v3.0-course-correction（二者降为历史件，保留供考古）。
> 写法为拷打优化：重大决策附**为什么/代价/推翻条件**；[D#]=decision-log.md 条目，[A#]=assumption-registry.md 条目，[E#]=evidence.md 条目（每条可复现）。

## 0. 产品定义

万历是一个**政企互动推演场引擎**：多层政府、区域与企业共同塑造产业政策结果的动态环境。它展示统一政策如何变成不同的地方现实、企业如何据此跨区域配置资源、这些适应行为如何反过来改变地方竞争与下一轮政策。光伏 2009–2018 是第一个完成史实校验的场景包（Exhibit A），新能源客车骗补包是可移植性的 30 秒换包证明 [D2][D8]。48h 交付形态仍是"一深一薄"：通用性必须靠一个打穿的案例证明，评审是经济学家，会往深处扎 [D1]。

## 1. 架构三层与两条原语

**物理层（状态中心）**：引擎 engine2.js。状态 = 主体（8 名角 + 约 230 动态群演，各带产能/现金/成本/记忆/特质）+ 区域制度（3 制度带 + 4 名角省）+ 市场聚合量。时钟 = 半年一回合 × 20。市场为全国单一出清（成本加权分配），价格由供需比幂函数生成。**为什么主体流而非项目为状态中心**：项目视图可从状态流免费投影（[E10]：55 实体项目/8 幽灵项目从零 Project 类的引擎中派生），反向不成立——状态中心必须是能派生对方的一侧 [D15]。

**合同层（v2）**：项目 = 政企谈判的双边承诺记录 {企业, 地区, 承诺产能, 配套条件, 里程碑}；生命周期 = 里程碑推进；烂尾 = 违约事件喂台账明细行。这是"谈判/一事一议/对赌"的正确安置层，不是状态中心 [D15]。

**视图层**：台账、项目生命周期皮肤、三镜头面板，全部是查询。

**原语一：廉价平行宇宙** `spawn(种子, 政策序列, 覆盖项)`。确定性引擎毫秒级重演任意宇宙；覆盖项可以是政策、制度参数或行为规则开关。时间线回看/分叉、双宇宙对照、Shapley 归因、敏感性扫掠全部是它上面的查询。**代价**：LLM 不得进入状态转移环（LLM 名角走缓存回放，评委碰旋钮时该回合真算并缓存）[D-记于 v2.1 诚实边界]。

**原语二：可归因事件账本**。每主体每回合五段决策卡（观测→调取记忆→规则→行动→独白）+ 资金流 + 政策操作史 + 承诺-兑现台账。三镜头 = 账本上的三种对照查询（§7）。

## 2. 因子体系（推演场的元语言，五张表）

场景包 = 五张表的一次实例化 + 掩码：①政策因子库（供给成本/需求产出/准入秩序/监督问责/贸易外部五通道，每条带 theory_ref 与参数域）；②企业行动契约 {进入/退出, 扩产, 研发, 合规姿态, 定价, 选址, 迁址, 游说(开关默认关 [A16])}——光伏包掩码开 {扩产, 研发, 合规, 进入选址, 迁址}；③主体 trait 六维（rnd/expand/risk/integrity/herd/patience，产业无关）；④制度因子（省级：优惠能力/兑现信誉/执行折扣/要素成本，从公开指数映射 [A6-9]）；⑤结果因子（财政/流失/成本前沿/集中度/存活谱/舆情/区域份额）。

## 3. 政策系统：政策树

21 节点 × 5 支线，行动点 3/回合（理性疏忽的政府侧），解锁三类（前置依赖/状态解锁如平价上网需 Cf<4/时间窗如双反谈判仅 t5–7），装机⊕度电互斥。**GR 安全规则**：史实自动驾驶只点亮校准三件套（装机/度电/核查），其余 18 节点是用户的反事实能力，效果只做加法不动基线路径——节点化剧本编译与旧三元组 20/20 回合逐位等价 [E2]。节点效果系数全部占位 [A10]。全表与编译器契约见 policy-tree-spec.md。**推翻条件**：若拷打证明行动点预算让史实回放不忠实，或互斥设定与史实混合补贴期冲突到影响校验，则重开混合补贴设计（backlog 已有卡）。

新增两席的决策原型零随机数（随机流纪律）。垂直一体化席被否：需要多环节市场，backlog [D13]。群演约 230 家动态种群（初始 200，典型一局新设 55/出清 168 [E10]），幂律规模、八字段独立状态、向量化独立决策；**类型配比赛前由 A 股聚类喂入、总量与尾形由行业普查口径喂入**（上市公司定比例与头部、普查定总量与尾巴 [D7][A12]）。24 家具名配角 = UI 层给名字与驻地，引擎零改动（前端卡）。与斯坦福小镇的对照定位：他们 25 个全深度求可信社会性，我们约三百个独立决策体排成金字塔求可审计因果——深度花在戏剧密度处，广度花在统计承重处 [D17]。

### 政府侧（32 行动体 + 17 席位）
| 层 | 数量 | 驱动 | 说明 |
|---|---|---|---|
| 中央 | 1 | **玩家席 + 史实自动驾驶** | 刻意不做自主 agent：中央内生化=风洞退化为观景台 [D5]。"中央按规则自动修正"仅作研究镜头场景选项（ai-economist 为基线参照） |
| 名角省 | 4（江苏/江西/河北/辽宁） | 深度规则 agent，**三席位票决**（招商/财政/监管），自带五段卡 | 席位立场全部从可测量量计算（中央核查、两期辖区虚报、份额偏离、财政自给率）；权重 CABW 每省 2–3 个自由参数 [A5]，正式反推校准等 P0-8 指数管线。选址与名角企业耦合：江西×维赛演软预算，辽宁×小盛演洼地 |
| 群演省 | 27 | 静态制度向量 + 指数驱动事件 | P0-8 管线：城投利差→兑现信誉、审计通报密度→执行折扣、财政自给率→优惠能力 |
| 媒体 | 机制 | 概率曝光过程 | 曝光率是政策树节点（名单公示），无升格必要 |

部门不做独立 agent [D6]：招商/财政/监管作为名角省决策卡内的**席位**，有立场、有可测输入、有可校准权重，省行动=票决结果——比独立部门 agent 少一堆无出处的议价参数，比纯叙事层多真实结构。已产出的机制事实：辽宁内阁在 2013 核查风暴中每期票决"维持 0.45"（招商席 1.3 压监管席 0.8），执行折扣从写死参数变成票决均衡；江苏/河北同期加严 [E4]。**适用边界（诚实披露）**：①票决只管执行折扣——救助通道不经票决、触发即执行（政治逻辑压倒财政逻辑的规范设定 [A22]，江西财政席二十期全程 −1 而救助两次照发）；②折扣的物质作用面=查处概率+名角决策闸，群演的造假决策不看本省折扣（effA 无省份维度 [A21]）。巡查组为何有效：discountMul 不经过内阁，直插。

## 5. 区域与地图

三制度带（沿海/中西部/东北）为制度聚类簇心与回退层；渲染与最终形态为**真实中国地图**（34 省级单元，echarts 压缩坐标现场解码→three.js 挤出）。三护栏 [D4]：①省级制度参数从公开指数**映射**而非自家评价（城投利差是市场给地方政府信用定的价），校验页公开映射公式；②政府 agent 名角/群演分层；③公开发布换自然资源部审图号标准地图（含南海诸岛插图），叙事事件不对真实省份作无出处负面断言。选址函数 U_j = α·优惠·信誉 + β·集聚 − 成本 + 洼地虹吸 + ε，从 3 带扩 31 省只换取值域不换公式。

## 6. 企业镜头与动作空间

控制回路：`step(policy, ctrl)`——玩家决策与 AI 走同一套现金约束与上限钳制；AI 决策函数照常运行仅覆盖结果（随机流对齐）；玩家动作自动生成五段卡（规则栏="玩家指令"）。**反事实纪律**：对照必须同控制结构（两宇宙都玩家控制，仅差被检验的那个选择）。动作现状：扩产/研发/合规姿态/进入选址/迁址（费 35%×K×capex [A2]、冷却 4 期、当期出货折半）；退出=破产内生或跨界主动；定价被出清吃掉；游说=注册表开关默认关 [A16]。**多区域产能摆放走"进入选址+迁址"的 v1 路线，多 home 为 v2 手术** [D10]。承诺-兑现台账 = 地方配套通道（承诺=加码×中央补贴，实付=×兑现信誉；`localMatchK` 基线 0、企业镜头场景开 1.0 [A3]）的免费副产品，一局输出兑现率 沿海85%/中部70%/东北26% [E6]。已知负结果（诚实入档）：现版制度差异对诚实企业现金流咬合不足，迁址期权对诚实小厂定价≈0——佐证"要素成本进损益"v2 牙 [E6][A14]。

## 7. 三镜头（同一账本的三种对照查询）

**政府镜头**：①执行偏差 = 名义→落地瀑布（核查 70 → C 省 ×(1−0.45) = 实核 39；补贴 → ×兑现信誉）；②预期偏差 = **设计者预期宇宙**（同质理性合规无记忆企业）与实际宇宙做差，通道消融分解到信誉折扣/资金约束/记忆疤痕/羊群/物种构成——把卢卡斯批判做进推演场。动机层"为何"由名角省内阁卡回答（§4）。

**企业镜头**：谁可信=台账；同行怎么摆=市场情报面板（"完全透明"是假设 [A15]）；资源放哪=U_j 分解 + 我的反事实自己（个体 P&L 双宇宙）。玩家换位=第二人格=评审"有人想用"的第二张票。

**研究镜头**：①因素归因——**先指定反事实语义**（叠加于史实/分叉冻结/时点前移：同一组合拳三种定义三个答案 [E5]），然后 Shapley 分解（十种子平均：巡查组 4.5 亿/处罚 5.7/规范 0.8；单种子可翻符号→种子层敏感性非可选项 [E5]）；②敏感性三层：种子（蒙特卡洛）/参数（输出**结论适用域**与翻转边界而非点估计）/规范设定（假设注册表的规则开关批量扫）；③假设注册表 = 每条行为规则有 ID + 可替换变体，"对哪些假设敏感"从修辞变成可执行批处理。

## 8. 决策可视化（概要，实现细则=第二梯队 spec）

原则：**默认安静、异常发声**——显著度评分（规则切换/赌注/意外度/记忆参与/离翻转边界距离）驱动一切。四件套按性价比排序：①决策剧场四拍（信号广播→观测浮签→思考：记忆连线从时间线格拉弧到主体+规则徽章→行动结算），关键回合自动上演；②规则徽章+热力图（规则 ID 表与假设注册表同一张表）；③翻转因子 ⚡ 进五段卡第六段（探针已验证：小盛翻转点=实核 55，记忆植入后全域收手→主导层判定 [E8]）；④决策链胶片（20 格连环画，引擎前置 f.cards 全史）。引擎前置三件：f.cards 全史 / 探针 API 产品化 / 规则 ID 表。

## 9. 校验体系与"校准≠验证"答辩

GR1–9 现值见 [E1]。三级论证预置：①**机制内置 + 时点复现**（史实剧本下：天阳 t8=尚德 2013.3、崩盘期 P<Cf、死亡潮 133 家/峰值 50、骗补仅存在于装机时代。措辞说明：机制是设计进去的，复现的是量与时点，不宣称"结构自发涌现"）；②**out-of-fit 反事实**——校准只锁史实一条轨迹，剂量反应实验（核查 20→骗补全域 101/64/48；70→仅剩洼地 0/0/46；树内顶格 80→0/0/45；100 仅裸三元组可达、树内玩家不可达 [A23][E11]）与干预实验（t3 早转度电 → 流失 0 且财政 1369 亿 > 基线 960 [E3]）检验的是**未被拟合的行为**，这是对"你的验证就是你的拟合目标"的正面回答；③**消融**（去记忆/去异质性/去区域层，逐个拆掉看哪条史实断言失守）。重校准披露制度：动基线必留痕（8 名角扩容案例：D0 5.8→6.10、新人体量 0.22/0.20、绑定型斜率 0.37→0.24，三迭代收敛，天阳点锚复位 [E1]）。

## 10. 已知软肋（拷打瞄准点，如实自供）

1. 政策树 21 节点效果系数全占位、量纲无出处 [A10]——最大面积的软肋。
2. CABW 内阁权重手调到能复现史实（"票决的均衡"当前有循环味），正式反推等 P0-8 [A5]。
3. 需求侧薄：外生基线×政策弹性，双反纯外生（ceteris paribus 明示）[A11]。
4. LLM 层至今是插槽：名角三层决策的顶层未接，全部现役行为是规则驱动。
5. GR 双重身份（拟合目标+验证标准）——答辩在 §9②，但 out-of-fit 断言集仍应扩充。
6. 制度差异对诚实企业咬合不足（[E6] 负结果）——要素成本通道 v2。
7. 单一环节市场：多晶硅-硅片-电池-组件纵向传导缺失（2008 硅料崩盘是光伏史大戏），backlog。

## 11. Demo 剧本 v3.1 骨架（5 分钟）
